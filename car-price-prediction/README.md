# Used Car Price Estimator

A small, reproducible supervised-learning exercise. The script generates synthetic rows, trains a scikit-learn pipeline, reports evaluation metrics, and predicts an example record.

> Every row is generated by a made-up formula. These outputs do not describe real listings or establish real-market model accuracy. Do not use them for a purchase or valuation decision.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python train_model.py
```

Python 3.10+ is recommended. The script writes `data/synthetic_used_cars.csv`.

## Code walkthrough

1. **Imports and paths:** `Path` anchors output next to the script; NumPy creates seeded sample values; pandas builds and writes a table; scikit-learn supplies splitting, preprocessing, pipeline, estimator, and metrics.
2. **Synthetic data:** `make_synthetic_data()` generates fictional make, age, mileage, engine size, fuel, and transmission columns. It combines a starting value, exponential age depreciation, mileage penalty, category adjustments, and random noise to create `price_gbp`. The model learns this artificial rule, not actual market behavior.
3. **CSV output:** `main()` makes the `data` folder and saves the DataFrame without a redundant index column.
4. **Feature preparation:** `ColumnTransformer` applies `StandardScaler` to numeric columns and `OneHotEncoder(handle_unknown="ignore")` to categorical columns. Scaling is included for learning; tree models generally do not require it.
5. **Model pipeline:** `Pipeline` chains preprocessing with `RandomForestRegressor` (250 trees, minimum leaf size 2, fixed seed). It keeps training and prediction transformations consistent. These are example settings, not tuned production values.
6. **Evaluation:** `train_test_split` holds out 20% of generated rows. MAE is average absolute error, RMSE gives larger errors more weight, and R² compares performance to predicting the test-set mean. The holdout uses the same synthetic formula, so these metrics cannot establish real listing accuracy.
7. **Prediction:** the sample DataFrame uses the same feature names and the fitted pipeline prints an illustrative estimate.

## Improving the study
For real research, source a documented, licensed dataset; record collection dates and currency; compare against a baseline; inspect missing data and leakage; use cross-validation plus a final untouched test set; and communicate prediction uncertainty.
