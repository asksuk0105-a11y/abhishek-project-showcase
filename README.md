## How the showcase works

- **HTML** defines page landmarks, headings, project cards, mock screens, and filter buttons.
- **CSS** handles the responsive project layout, cards, colors, and narrow-screen rules in the `<style>` block.
- **JavaScript** at the end of `index.html` filters project cards by category and updates each filter button's `aria-pressed` state.
- Native links and buttons, heading hierarchy, and a named navigation landmark provide basic accessibility support. This is not a certified accessibility audit.
