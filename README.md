# Academic & Portfolio Projects

**Abhishek Singh · 2023–present**

This repository presents selected academic-style and self-directed project concepts across e-commerce, healthcare operations, and AI-supported learning. The web page is a responsive project showcase; the interface previews illustrate proposed workflows and are not connected to live services.

## Projects

- **Marketday Online Store** — storefront, product discovery, basket, and checkout journey concept.
- **Carepoint Hospital Manager** — appointments, patient flow, care-team schedules, and dashboard concept.
- **Studywise AI Learning Companion** — student-led study planning and responsible AI guidance concept.

## Open the showcase

Open `index.html` in a browser or visit the [live showcase](https://asksuk0105-a11y.github.io/abhishek-project-showcase/). It uses plain HTML, CSS, and JavaScript and requires no build step or external dependencies.

## Scope and implementation notes

These are portfolio demonstration concepts. The included screen previews are static UI mockups; they do not connect to a backend, store patient records, process payments, or call an AI service. No real patient or customer information is used.
